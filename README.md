# Soran Hookah Shop — POS

سیستەمی فرۆشتن و بەڕێوەبردنی دوکان (React + TypeScript + Vite + Supabase).

## دامەزراندن بۆ یەکەم جار (گرنگ — بەم ڕیزبەندییە)

1. **پاسۆردی داتابەیس بگۆڕە** — Supabase → Project Settings → Database → *Reset database password*.
   (پاسۆردە کۆنەکە لە فایلێکی کۆندا بە ئاشکرا نووسرابوو.)
2. **SQL ـی ئاسایش جێبەجێ بکە** — Supabase → SQL Editor → New query →
   ناوەڕۆکی `supabase/01_security_and_sales_upgrade.sql` دابنێ → **Run**.
   - هەموو پاسۆرد و PIN ـەکان دەگۆڕدرێن بۆ hash (bcrypt) و کۆپییە ئاشکراکان دەسڕدرێنەوە.
   - خشتەی `staff_users` لە کلیلی گشتی (anon) دادەخرێت.
   - فرۆشتن بە یەک transaction تۆمار دەکرێت و کۆگا لەسەر سێرڤەر کەم دەکرێتەوە.
   - چەند جار جێبەجێ بکرێت کێشە نییە.
3. **SQL ـی تۆماری چالاکی جێبەجێ بکە** — هەمان شێوە، ناوەڕۆکی `supabase/02_activity_audit.sql` → **Run**.
   لەمەودوا هەموو زیادکردن، دەستکاری و سڕینەوەیەک لە هەموو بەشەکان خۆکار تۆمار دەکرێت
   (کێ، کەی، چی، و نرخی کۆن ← نوێ). تۆمارەکان ناتوانرێن لە ئەپەکەوە بسڕدرێنەوە یان بگۆڕدرێن.
4. ئەپەکە build و deploy بکە:
   ```bash
   npm install
   npm run build
   vercel --prod     # یان هەر ڕێگایەک کە پێشتر بەکارتهێناوە
   ```
5. هەموو کارمەندان یەک جار دەردەچن و دەبێت دووبارە بچنە ژوورەوە (پاسۆردەکانیان نەگۆڕاوە).

> ئەپە نوێیەکە پێش جێبەجێکردنی SQL ـیش کار دەکات (بە شێوازی کۆن)، بۆیە ڕیزبەندیی ٢ و ٣ مەترسیی داخستنی دوکانی نییە.

## گۆڕانکارییەکانی ئەم وەشانە

### تایبەتمەندیی نوێ
- **گۆڕینی نرخ بە کۆمەڵ** (کاڵاکان → «گۆڕینی نرخ بە کۆمەڵ» یان «هەڵبژاردن و گۆڕینی نرخ»):
  چەند کاڵایەک هەڵبژێرە، پاشان نرخی فرۆشتن / تێچوو / تەک / نیو تەک بگۆڕە بە
  ٪ زیادکردن یان کەمکردن، بڕێکی دیاریکراو، یان نرخێکی نوێ. نزیککردنەوە بۆ 250 / 500 / 1000 هەیە،
  پێش جێبەجێکردن هەموو گۆڕانکارییەکان پیشان دەدرێن، و ئاگادارت دەکاتەوە ئەگەر نرخی فرۆشتن لە تێچوو کەمتر بێت.

### ئاسایش
- پاسۆرد و PIN بە hash هەڵدەگیرێن. چوونەژوورەوە و قوفڵی شاشە و بەڕێوەبردنی بەکارهێنەران بە session token کار دەکەن.
- پەڕەکان بەپێی دەسەڵات پارێزراون. کاشێر ناتوانێت بە نووسینی لینک بچێتە `/settings` یان `/users`.
- فایلی `update_schema.js` (کە پاسۆردی داتابەیسی تێدابوو) سڕایەوە، و `.env` خرایە ناو `.gitignore`.

### چاککردنی هەڵەکان
- کۆگا لە کاتی فرۆشتندا لە دوو ئامێردا هەڵە نابێت، چونکە لەسەر سێرڤەر کەم دەکرێتەوە.
- گەڕانەوەی کاڵایەک کە بە «تەک» یان «نیو تەک» فرۆشرابوو، ئێستا ژمارەی دروستی دانە دەگەڕێنێتەوە کۆگا.
- لیستی کاڵا و کڕیاران لە ١٠٠٠ ڕیز زیاتریش هەمووی پیشان دەدرێت (پێشتر دەبڕا).
- باکئەپ هەموو ڕیزەکان و خشتەکانی پۆل، ڕێکخستن، خەلتە و تۆماری چالاکیشی تێدایە (پێشتر لە ١٠٠٠ ڕیزدا دەبڕا).
- پێش گەڕاندنەوەی باکئەپ فایلەکە دەپشکنرێت و باکئەپێکی پاراستن خۆکار دادەبەزێت. ئەگەر هەڵەیەک ڕووبدات ڕادەگەیەنرێت (پێشتر داتا دەسڕایەوە و هەڵەکان بێدەنگ دەمانەوە).
- لە پەڕەی جۆرەکان و کۆمپانیاکان، مەوجوود و نرخ بەتاڵ پیشان دەدران؛ ئێستا چاککرا.
- ئەگەر کاشێر بڕی پارەی نەقدی نووسیبا و دوایی بیگۆڕیبا بۆ قەرز، ئەو بڕە بە هەڵە وەک پارەی دراو تۆمار دەکرا؛ ئێستا چاککرا.
- هەڵەکانی TypeScript و ١٠٧ import ـی بەکارنەهاتوو لابران.

### خێرایی و دیزاین
- هەر پەڕەیەک تەنها کاتێک دەکرێتەوە بار دەکرێت، بۆیە فایلی سەرەتایی زۆر بچووکتر بووە و ئەپەکە خێراتر دەکرێتەوە.
- **لیستی لای ڕاست (sidebar)** بۆ شاشەی گەورە، بە گرووپی فرۆشتن، کۆگا، دارایی و سیستەم.
- لە جیاتی پەنجەرەی `alert` ـی وێبگەڕ، ئاگادارکردنەوەی جوان و بێ‌ڕاگرتن پیشان دەدرێت.
- ژمارەکان لە خشتەکاندا ڕێک دەکەونە ژێر یەکتر، focus ـی کیبۆرد ڕوونترە، و `dir="rtl"` بە دروستی دانراوە.
